# 🏆 Beltone Hackathon – Gold Price Prediction

This project was developed as part of the **Beltone Hackathon** in Egypt, held in **October 2024**. The challenge was to create a machine learning model capable of predicting **gold prices** in the local market using historical data.

## 💡 Project Overview

The goal was to design a robust time-series forecasting model that could handle noisy and non-linear financial data. The solution needed to balance accuracy with generalization to real-world fluctuations in the market.

---

## 🔧 What I Did

- Collected and preprocessed historical gold price data.
- Engineered time-based features such as moving averages, volatility indicators, and lag features.
- Applied **XGBoost regression**, which outperformed traditional models due to its ability to model non-linear dependencies.
- Tuned hyperparameters using grid search and cross-validation.
- Evaluated performance using RMSE and directional accuracy.

---

## 🛠 Technologies Used

- Python
- Pandas & NumPy
- Scikit-learn
- XGBoost
- Matplotlib & Seaborn (for visualization)
- Jupyter Notebook

---

## 📊 Results

- The model demonstrated high accuracy on validation data and effectively captured short-term trends.
- Feature importance analysis revealed key drivers such as recent price movements and volatility.
- Achieved strong performance compared to baseline time-series models (ARIMA, linear regression).
